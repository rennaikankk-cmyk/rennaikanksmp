# RennaikankSMP

面向 Minecraft 1.21.11 的 Fabric 客户端 mod，服务于生存 / 粘液科技 / 无规则服务器游玩。

本仓库是 [SlimefunHelper](https://github.com/m1919810/SlimefunHelper)（作者 matl114 / m1919810，CC0-1.0）的 fork，在其基础上做了两块大改造。上游的完整功能说明见 [README_UPSTREAM.md](README_UPSTREAM.md)。

## 本 fork 的改动

### ClickGui 视觉全面现代化

- 世界内打开 ClickGui / 居中弹窗时背景自动暗化（强度可调，可关闭）
- 顶部标签条：深色工具条 + 选中页 accent 下划线（替代原版按钮贴图）
- 模块窗口：渐变标题头 + 窗口描边 + 软阴影，多窗口叠放层次清晰
- 模块按钮：渐变底 + 启用状态左侧 accent 竖条 + 悬停高亮
- 配置页：整体面板化（面板跟随列表高度与滚动）
- 细滚动条、现代搜索框边框
- GuiSettings 页内置四套主题预设（紫 / 深蓝 / 史莱姆绿 / 暗红），点击即时整套换色

### ElytraBotV2（与原 ElytraBot 并存，可切换）

原版 ElytraBot 之外新增的目标智能驱动版本：

| 能力 | 说明 |
| --- | --- |
| 图腾感知 | 对手持图腾不俯冲，头顶盘旋等待图腾爆裂瞬间切入俯冲窗口 |
| 珍珠拦截 | 检测目标末影珍珠并模拟落点（重力/阻力/方块射线），直接拦截落点 |
| 攻击节奏 | 所有攻击统一走 冷却进度阈值 + 最小间隔 双门槛 |
| 反矛诱骗 | 周期随机换向漂移诱骗预瞄，对方矛充能完成瞬间硬闪避 |
| 矛手交战窗口 | 对方矛花掉后 40tick 突进输出 |
| 自动架矛 | 俯冲自动换矛 + 按住使用充能，戳刺不再白板（原版从未发送使用动作） |
| 最高伤害戳刺 | 戳刺门槛 = 充能满 + 速度峰值（动能伤害随撞击速度缩放） |
| 跟随地形感知 | 前方射线探测，撞墙前按接近度自动爬升 |

与 V1 运行时互斥：V1 开启时 V2 自动让位。

## 构建

需要 JDK 21：

```
./gradlew build
```

产物在 `build/libs/rennaikanksmp-1.21.11-<version>.jar`，直接放入 `.minecraft/mods`。

依赖：Fabric API（必须）、ViaFabricPlus（强烈推荐）。

## 使用

- 多人游戏菜单右上角按钮，或游戏内 **右 Alt** 打开 ClickGui，全部参数在 GUI 内配置
- 指令前缀 `!!` 或 `/!!`
- 本 mod 是客户端 mod，**不要**放进服务端 mods
